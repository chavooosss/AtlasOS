# AI-generated Atlas project assets

**Reviewed:** 2026-10-05

AtlasOS-owned source code is covered by the repository MIT license where applicable. AI-generated Atlas project assets are tracked separately; MIT does not establish their copyright ownership or override a generation provider's terms.

The project owner attests that the Atlas-specific logo, visual/UI/Plymouth artwork, and startup media reviewed for this project were generated using AI tools for AtlasOS and were not knowingly copied from third-party asset files. The owner directs publication of the visually reviewed Atlas assets that this inventory marks `AI-GENERATED-CLEARED`. That status means project-distribution permission is recorded for AtlasOS; it does **not** claim exclusive copyright, public-domain status, a provider warranty, or a trademark registration.

Provider and model are not reliably recorded for the cleared visual assets. The string `seedream` in one filename is not sufficient to identify a provider. Provider output terms therefore remain unverified for those assets. If a provider is later identified, review the terms applicable on the actual generation date and plan before making broader ownership or commercial-use claims.

## Review rules

- Retain the asset path, project purpose, provenance source, provider/model if known, creation date if known, human edits, source inputs, and terms-review status.
- AI generation by itself does not mean public domain, exclusive copyright, or freedom from third-party rights.
- Review outputs for recognizable logos, trademarks, characters, copied interfaces, people/voices, and other third-party material. “No obvious third-party content” is a limited project review, not a legal guarantee.
- Keep unknown provider/model/terms explicitly unknown. Do not infer a provider from filename or visual style.
- Keep assets excluded when third-party references, source inputs, audio samples, attribution, or plan status remain material and unresolved.
- Reassess rights if an asset is materially changed, a provider is identified, or use expands beyond AtlasOS project distribution.
