# Brand and trademark use review

This is a source-tree review, not permission from any mark owner. Avoid wording or presentation that implies endorsement, certification, or official integration.

| Reference | Classification | Publication handling |
|---|---|---|
| Ubuntu | Textual compatibility reference / upstream package identity | “Ubuntu-based” is a factual platform description. No Canonical endorsement is claimed. The exact historical ISO has not received a complete visual mark scan. |
| Canonical | Upstream copyright/brand owner reference in package/font notices | Preserve factual notices; do not imply affiliation. |
| Google / Chrome | Historical package and historical validation references | Removed from future build selection and active launcher UI. Historical records remain factual and are not current package claims. |
| MEB, EBA, OGM, MEBİ | Textual compatibility/service references in UI and documentation | Use nominative references only; no official service integration or endorsement is claimed. Any copied logos/brand artwork require separate clearance. |
| Adwaita / Papirus | Upstream package identity | Prefer installed upstream icon-theme packages and their notices over copying icon files. |
| AtlasOS logo, Plymouth artwork, and reviewed UI illustrations | Owner-attested AI-generated Atlas assets | Project-distribution permission is recorded separately from source licensing; provider/model terms are unknown and exclusive copyright is not claimed. The startup WAV remains excluded. |
| Pardus mark/image and user/environment photos | Third-party or privacy-sensitive visual material | Excluded unless individually rights- and privacy-cleared. |

Root MIT does not grant trademark rights. Before public binary publication, inspect the exact candidate image for remaining upstream/vendor marks and remove any endorsement-like presentation.
