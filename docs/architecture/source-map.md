# Canonical source map

| Canonical source | Generated / packaged derivative | Classification |
|---|---|---|
| `config/includes.chroot/usr/local/share/atlasos/ui/` QML, components, theme | Same tree copied into live-build workspace and installed in Live filesystem | SOURCE → GENERATED PACKAGE |
| `config/includes.chroot/usr/local/bin/` launchers/services | Live root filesystem | SOURCE → GENERATED PACKAGE |
| `config/hooks/`, `config/package-lists/`, `iso/build-atlasos.sh` | live-build config, root filesystem and hybrid ISO | BUILD SOURCE → RELEASE |
| `iso/grub-console.cfg` | GRUB config embedded in generated EFI image / ISO | SOURCE CONFIG → GENERATED EFI/ISO |
| `atlas-boot/src/`, `Cargo.toml`, `Cargo.lock` | host renderer and UEFI `.efi` under Cargo `target/` | SOURCE → GENERATED BINARY |
| `atlas-boot/tools/` plus original fonts/art assets | raw embedded/generated Boot Manager assets | TOOL/SOURCE ASSET → GENERATED ASSET |
| `assets/branding/` source SVGs and generators | copies under `config/includes.chroot`, Plymouth artwork and raster derivatives | SOURCE → GENERATED/PACKAGED ASSET |
| `tests/` and fixtures | test reports, screenshots, QEMU captures | TEST SOURCE → GENERATED EVIDENCE |
| build scripts + source tree | `dist/` ISO, EFI, images, extracted filesystems, logs | SOURCE → RELEASE/VALIDATION OUTPUT |

`config/includes.chroot` contains canonical Atlas implementation for the current build, not a separate upstream source mirror. If duplicated source copies are added later, identify one authority before changing them. `dist/` is never canonical source. Phase 6B/6C backend config is generated by integration tooling and must be treated as generated integration output. The final ISO is a release artifact, not a normal source file.
