# AtlasOS product screenshots

These selected images document the current AtlasOS interface implementation. The desktop, Quick Settings, network, Settings, and power-menu PNGs were rendered directly from current AtlasOS QML with the project’s offscreen PySide6/QML smoke renderer at 1920×1080. They are implementation captures, not image-generated mockups, post-composited artwork, or captures from a complete running OS/VM. Backend values and unavailable controls reflect the local smoke-render environment.

The Boot Manager PNG is the existing project visual at `website/public/images/atlasos-boot-manager.png`, copied without editing. The selected screenshots were checked for personal filesystem paths and host hardware details. Other review captures containing a local workspace path or host hardware inventory were deliberately left out.

Some desktop screenshots visibly include textual EBA, OGM Material, or MEBİ shortcuts. These are local resource references only; they do not imply service integration or endorsement. Underlying brands remain the property of their respective owners. No reference mockup or personal/device photograph is included here.
