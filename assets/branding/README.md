# AtlasOS logo assets

The project owner attests that Atlas-specific logo and artwork in this family were generated for AtlasOS using AI tools and were not knowingly copied from third-party asset files. Provider, model, prompts, and generation terms were not retained. The word “seedream” in a filename is not treated as proof of a provider. See [AI-generated asset policy](../../docs/legal/ai-generated-assets.md), [provenance attestation](../../docs/legal/asset-provenance-attestation.md), and the [asset inventory](../../docs/legal/asset-inventory.json).

- `atlasos-logo-seedream-master.png` is the original 2048×2048 project logo image recorded as supplied and approved by the owner on 2026-09-29.
- `atlasos-emblem-traced.svg` is a two-color vector trace derived from the master using Pillow, NumPy, and OpenCV.
- `export_atlasos_branding.py` creates UI, Plymouth, monochrome, and GRUB SVG lockups from the traced emblem.
- `generate_plymouth_sweep.py` creates 24 deterministic orbit-light frames from the Atlas logo.

Project publication permission for reviewed Atlas assets does not assert exclusive copyright and does not replace provider terms. The UI concept screenshot and startup audio remain excluded as recorded in the inventory.
